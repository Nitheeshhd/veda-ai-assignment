 # 🚀 VedaAI – AI Assignment Generator

## 📌 Overview
This project is a full-stack AI-based assignment generator that allows teachers to create structured question papers.

Users can:
- Create assignments
- Generate question papers
- View structured output with sections, difficulty, and marks

---

## 🛠 Tech Stack

### Frontend
- Next.js (TypeScript)
- Tailwind CSS

### Backend
- Node.js
- Express.js
- MongoDB

---

## ✨ Features

- 📝 Assignment creation form
- ✅ Input validation
- 🔗 Backend API integration
- 📦 MongoDB data storage
- 🤖 AI-like question generation (structured)
- 📚 Section-wise question display
- 🎯 Difficulty + marks tagging
- 📄 Exam-style UI layout

---

## ⚙️ How to Run the Project

### 1. Install dependencies
npm install

### 2. Run project
npm run dev

### 3. Open in browser
http://localhost:3000

---

## 🧠 Approach

- Built a full-stack system with separate frontend and backend
- Used REST APIs for communication
- Managed form state using React state
- Generated structured questions using custom logic
- Designed UI similar to real exam papers

---

## 📌 Notes

- AI generation is simulated
- Focus on structure and clean UI
- Easily extendable to real AI
